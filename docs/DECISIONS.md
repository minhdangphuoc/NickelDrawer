# Decisions

| Date | Decision | Notes |
|---|---|---|
| 2026-10-08 | Stock Nickel UI, KOReader removed | User prefers the native Kobo look. |
| 2026-10-08 | Native drawer via NickelHook mod + UI kit (`ui.json`) | Menu (NickelMenu) stays as permanent fallback. |
| 2026-10-08 | Support the 5 newest Libra 2 firmware builds (4.38.23552 → 4.38.23828) | 4.x only; 5.x unsupported by NickelMenu / kobo-tieng-viet. See plan §3. |
| 2026-10-08 | Model routing: developer codes, reviewer debugs and reverse-engineers | See CONTRIBUTING.md. |
| 2026-10-08 | Any UI language: English source + `locales/<lang>.json` | **English and Vietnamese ship first** and are maintained by us; other languages come from community translations later. RTL layout deferred to UI kit phase. |
| 2026-10-08 | Public open-source project, name **NickelDrawer** | No GitHub repo with that name existed on 8 Oct 2026. |
| 2026-10-08 | License **MIT** | Matches NickelMenu, NickelHook, localgo. |
| 2026-10-08 | Public beta after gate G3 (mid-Nov 2026); v1.0 at G6 | Publish once drawer + failsafe are proven. |
| 2026-10-08 | OTA updates from GitHub Releases, signed with ed25519 | Private key stays on the maintainer's Mac; never in repo/CI. |
| 2026-10-08 | Repo owner: the maintainer's GitHub account (confirm before creating) | |
| 2026-10-08 | **Decline Kobo's optional "Qt6 upgrade"** (= firmware 5.x) on the Libra 2 | The server-offered upgrade flow (`ApplicationSettings::availableQt6Upgrade`, `HomePageController::maybeShowQt6UpgradeDialog`, `skippedQt6UpgradeUrl`) exists only in 4.38.23828; 4.38.23552–23697 have an older optional dialog (17 related symbols). It asks the user first: Skip/Cancel records the offered URL as declined (it returns only for a new URL); Proceed makes the next sync install it. See re/notes/G2-findings.md Q5. Accepting it would break NickelMenu, NickelDrawer and kobo-tieng-viet. Future: the drawer warns when `IOUtil::isQt6UpgradePending` is true. |
| 2026-10-08 | Symbol dumps (`re/symbols/*/exports.txt`, ~25 MB) not committed | Regenerate with `re/scripts/fetch-fw.sh` + `re/scripts/symreport.py`. |
| 2026-10-08 | Drawer: native list (sections "Installed" / "System", icon + name + status + chevron) is the default view; optional grid view behind a toggle in the header | Approved on the design canvas. Lives as one "Apps" row in Nickel's More tab, not a separate bottom tab. |
| 2026-10-08 | Hard keys: page-turn buttons flip pages (drawer list/grid and long app screens), ignored in dialogs/menus, follow Nickel's direction setting | Key-event delivery to a pushed view is a G2 item for Ghidra. |
| 2026-10-08 | Gate G2 (static): conditional GO for the native drawer | More-tab row via MoreView hook (NickelMenu recipe); drawer as AbstractController subclass with navSection 6 (keeps tab bar, More active); page keys arrive as arrow keys via TactileButtonFilter; plan B = full-screen N3Dialog. Needs on-device prototypes before G2 is signed. See re/notes/G2-findings.md. |
| 2026-10-09 | GitHub sync on device postponed by the user | Code, pairing and tests stay; device acceptance (GH-*) moves to a later session. Repo `main` branch currently has no books. |
| 2026-10-10 | Keep current app screens; no Settings-style options window or Kobo Settings row for now | Improve back instead: working arrow on app screens, one-level back stack restoring the previous view (page + list/grid). |
| 2026-10-10 | Apps talk only through the NickelDrawer API (JSON events) and Nickel functions via the host; no NickelMenu-style text dialogs in the drawer | Device: "Bắt đầu nhận" showed the script's old text dialog on top of the native screen. |
| 2026-10-10 | NickelMenu tab removed from the nav bar; tweaks move to a native "Tinh chỉnh" row in Thêm (run via the NickelDrawer API / Nickel functions). NickelMenu may stay installed but is no longer a fallback: apps no longer generate NickelMenu items | Nav bar back to Nickel's 4 tabs. Reader-menu Dark Mode item stays. |
| 2026-10-10 | "Tinh chỉnh" opens as a Settings-style modal (small centred title, ✕ close, large serif title, italic serif rows with dividers) with the tweak actions in a 2-column list; toggles show Bật/Tắt; reboot actions confirm | User reference: Kobo's Cài đặt window. |
| 2026-10-10 | Drawer drops app prose; no NickelMenu generation | `drawer run`/`event` return only toast/dialog signals from apps (other output goes to stderr, failures become a short localized message). `gen-menu`, `refresh`, `errors` removed; the installer deletes `.adds/nm/koboapps` (after backup) and sets `experimental:menu_main_15505_enabled:0`. Tweaks backend is `appsctl drawer tweaks`/`tweak` (docs/spec/tweaks.md). |
| 2026-10-10 | Viewer full view (chrome hidden) gets a visible back button at the top left that shows the chrome again | Device: with the chrome hidden the only way back was the unmarked centre third; taps where `←` had been flipped pictures (or did nothing at the first picture). Back stack: full view → viewer → gallery. |
| 2026-10-10 | Icons come from Nickel's own resources first, then Tabler Icons (MIT), never our own drawings | User: hand-drawn icons looked wrong next to Nickel's. Details in re/notes/system-icons.md. |
| 2026-10-10 | Skip the 72 h idle/usage soak for G3 and G5; gates pass on the device test session alone | User decision. Debug logging stays on in the beta so long-run problems still show up in debug.log. |
| 2026-10-10 | Drawer grid is a 4-column launcher grid: borderless 280 x 240 cells on the content gutters, 96 px icon over a centred 2-line name, no status line, rows = as many as fit; host items (refresh, updates) become header icon buttons | Device photo: 3 big bordered tiles, icon and label far apart, status squeezed in, third tile offset, refresh shown as an app. Cell math is pure and unit-tested (`drawer_logic`), cells are placed by it, not by a layout, so none drift. |
| 2026-10-10 | JSON-lines long-running app backend dropped | Apps are short action scripts plus a `state` action that the mod re-reads every 5 s while a screen is open; scripts answer with JSON signals (`toast`, `dialog`, `request`). Simpler, nothing to crash inside Nickel, and testable on the Mac. Plan §7.7 stays as a design record only. |
| 2026-10-10 | NickelMenu is not a fallback | Unknown firmware: the drawer turns itself off (More tab stock), shows one toast and logs the reason; there are no generated menu items to fall back to. Implemented by the mod; rehearsed with the flag `.adds/nickeldrawer/test-unknown-fw`. |
| 2026-10-10 | Apps may ask the host for services | `app.json` `requests` lists `rescan` / `wifi`; a script prints `{"request":"rescan","mode":"quick"}` or a finished job puts `requests` in its `state`; `appsctl` validates and passes them to the mod. |
| 2026-10-10 | One signed release may carry the mod | `.adds/koboapps/mod/KoboRoot-nickeldrawer.tgz` in `release.json`; the updater verifies the signature and checks the archive holds only `usr/local/Kobo/imageformats/*.so`, then stages it as `.kobo/KoboRoot.tgz`; a reboot installs it. |
| 2026-10-10 | Installer installs and removes the mod | `tools/install-to-kobo.sh` stages the mod when it changed (`--with-mod`, `--no-mod`) and `--uninstall` removes drawer, apps and mod (flag `.adds/nickeldrawer/uninstall`), keeping inbox files and, when asked, app data. |
| 2026-10-10 | Screens are on by default | Opt-out flag `.adds/nickeldrawer/no-screens`; the old `screens` flag is ignored. |
| 2026-10-10 | License changes from MIT to PolyForm Noncommercial 1.0.0 (personal, study, hobby and non-profit use; no commercial use) | User decision. The project becomes source-available, not OSI open source. Third-party code (NickelHook, localgo, Tabler Icons, oksvg/rasterx) keeps its own permissive license. Contributions are accepted under the same license with the right to relicense. |
| 2026-10-10 | GitHub sync is back in 1.0.0-beta.1 (user, supersedes the 2026-10-09 postponement) | The app is visible again (`hidden` removed, version 0.2.0) with a main screen, a pairing screen and long actions that run detached and report through `state`. A 404 at pairing is now named: repository (or token access), branch or folder; an empty but readable repository pairs and syncs 0 books. Files are checked against the inbox allowlist (extension, size cap, magic bytes) and routed by type to `Books/GitHub`, `Documents/GitHub`, `Comics/GitHub`; names are stored in NFC. Device cases GH-01..08 are rewritten in `docs/sessions/T-final-checklist.md` §4b. |
